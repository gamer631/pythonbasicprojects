# Python Projects — Beginner to Intermediate

A practical collection of small Python projects. Run them, read the code, and extend them as you learn. This is a learning repository and is being built iteratively; project descriptions are honest about what each script does.

## Beginner
- `beginner/01_tip_calculator` — bill splitting and tip math
- `beginner/02_password_generator` — secure random passwords
- `beginner/03_quiz` — multiple-choice quiz and score
- `beginner/04_contact_book` — local JSON contacts
- `beginner/05_expense_tracker` — expense records and totals

## Intermediate
- `intermediate/06_file_organizer` — preview-first file sorting
- `intermediate/07_log_analyzer` — analyze common log levels
- `intermediate/08_habit_tracker` — local daily check-ins
- `intermediate/09_weather_cli` — current weather by coordinates
- `intermediate/10_task_manager` — JSON task list with priorities

Python 3.10+ recommended. Most use only the standard library. Example: `python beginner/01_tip_calculator/main.py`.
