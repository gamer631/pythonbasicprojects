# Beginner Python Projects

This repository contains simple beginner-level Python projects created in a step-by-step learning order.

## Project list

1. project1.py - Simple Calculator
2. project2.py - Number Guessing Game
3. project3.py - To-Do List
4. project4.py - Password Generator
5. project5.py - Rock, Paper, Scissors
6. project6.py - Quiz Game
7. project7.py - Dice Roller
8. project8.py - Simple ATM
9. project9.py - Temperature Converter
10. project10.py - Hangman Game
11. project11.py - BMI Calculator
12. project12.py - Expense Tracker

## How to run

```bash
python project1.py
```

Replace `project1.py` with any project file you want to run.

## Learning order

Start from `project1.py` and move to `project12.py` one by one. Each project uses simple Python concepts and beginner-friendly comments.
